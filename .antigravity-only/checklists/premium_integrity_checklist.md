# Premium Integrity Checklist

Premium is allowed only when it does not affect measurement or competitive fairness.

## Allowed premium examples

```text
Advanced history
Private insights
Guided plans
Visualizations
Personalization
Reports
Training reminders
Non-competitive convenience
```

## Forbidden premium examples

```text
Rating boosts
Ranking advantage
Easier scoring
More rated attempts that distort rankings
Exclusive ranked shortcuts
Difficulty advantages
Measurement changes
Hidden unfair matchmaking priority
```

## Review questions

```text
Does premium change rating? Yes/No
Does premium change ranking? Yes/No
Does premium change scoring? Yes/No
Does premium change measured difficulty? Yes/No
Does premium improve competitive opportunity unfairly? Yes/No
Does premium create perception of pay-to-win? Yes/No
```

Any `Yes` requires REVISE or NO-GO.
