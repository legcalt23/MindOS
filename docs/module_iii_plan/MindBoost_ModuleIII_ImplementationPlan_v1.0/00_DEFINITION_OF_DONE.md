# Definition of Done

A unit is "Done" when:
1. Code compiles without warnings.
2. All unit tests pass with synthetic data.
3. Terminology scanner reports zero violations.
4. Feature flags are confirmed default-OFF.
5. No production endpoint references exist.
6. Audit log entries are generated for every rating mutation.
7. Code review approved by at least 2 reviewers.
8. Documentation updated in the corresponding `.md` file.
9. Integration Validation Check (if applicable) passes.
