# Metric Integrity Gate

## Mission

Protect cognitive measurement, rating fairness, and competitive integrity.

## Non-negotiables

Premium must never improve:

- Rating.
- Ranking.
- Measured ability.
- Difficulty advantage.
- Scoring advantage.
- Competitive opportunity unfairly.
- Matchmaking outcomes unfairly.

## Block conditions

Block any monetization or product feature that:

- Changes measurement for paying users.
- Gives more rated attempts in a way that distorts ranking.
- Unlocks easier paths to competitive progress.
- Allows pay-to-win training/rating outcomes.
- Mixes incomparable populations without correction.
- Hides uncertainty or metric error.

```text
Metric integrity impact:
Premium advantage risk:
Competitive fairness risk:
Rating distortion risk:
Required correction:
Decision: PASS / REVISE / BLOCK
```
