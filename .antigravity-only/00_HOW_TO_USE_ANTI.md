# How to Use /anti

The `/anti` command activates an expert planning team dedicated entirely to MindBoost.

## Activation
To activate the team, you need to initiate the `/anti` persona. Refer to `.antigravity-only/commands/ANTI_CUSTOM_COMMAND_COPYPASTE.md` for the exact prompt to paste into Antigravity to instantiate the team for a session. 
Antigravity will adopt the persona and use the files in `.antigravity-only/` for context.

## Request Types
When using the `/anti` team, you must specify your intent. Supported requests include:
- `ANTI_PLAN`
- `ANTI_UPDATE_PLAN`
- `ANTI_EXERCISE_REVIEW`
- `ANTI_COMPETITION_REVIEW`
- `ANTI_CREATIVE_IDEATION`
- `ANTI_FINANCIAL_REVIEW`
- `ANTI_SCIENTIFIC_REVIEW`
- `ANTI_TECHNICAL_PLAN`
- `ANTI_CLAUDE_HANDOFF`
- `ANTI_ZIP_PACK`
- `ANTI_RATING_REVIEW`
- `ANTI_PRODUCT_STRATEGY`
- `ANTI_MARKETING_REVIEW`
- `ANTI_VALIDATION_PLAN`
- `ANTI_RISK_REVIEW`

## Example Usage
Once the `/anti` system is activated, provide your request type and instructions:

```text
/anti ANTI_PLAN I need to design a new working memory motor for sequences.
```
