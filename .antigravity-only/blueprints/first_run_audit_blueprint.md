# First Run Audit Blueprint

Use this for the first serious MindBoost audit.

## Goal

Inventory MindBoost and create a phased plan to improve MVP quality without implementation.

## Steps

1. Identify likely MindBoost files/modules.
2. Confirm non-MindBoost areas are not modified.
3. Inventory exercises.
4. Inventory metrics and rating logic.
5. Inventory onboarding/training/progress UX.
6. Inventory premium/business logic if present.
7. Inventory test coverage.
8. Identify scientific risks.
9. Identify metric integrity risks.
10. Identify KMP parity risks.
11. Generate creative opportunity field.
12. Generate financial evaluation.
13. Generate phased implementation plan.
14. Generate Claude Code prompts.
15. Generate ZIP.
