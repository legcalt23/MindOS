# 04 Science Review

**Metric Integrity beats Monetization.**

- **Evidence Level:** Medium/High for the 3 MVP motors.
- **Risk of Overclaiming:** High if user sees raw ratings. Keep ratings as backend features for adaptive difficulty.
- **Measurement Plan:** Use Bayesian rating solely for matching item difficulty to player skill, not player vs player.
- **Scientific Rationale:** Choice reaction and sequence updating are established constructs, but mobile touch screens introduce variable latency that confounds millisecond-level inference.
