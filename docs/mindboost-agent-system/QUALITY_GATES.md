# Mindboost Quality Gates

## Cognitive validity gate

- Clear domain
- Clear mechanism
- Measurable task
- Evidence classification
- No unsupported claims

## Product gate

- User knows what to do
- Feedback is immediate
- Progress is visible
- Friction is low
- Retention loop is ethical

## Engineering gate

- Fits existing architecture
- Typed where possible
- Validates inputs
- Tests important logic
- Observable through analytics

## Safety gate

- No diagnosis
- No clinical claims
- No guaranteed IQ claims
- No manipulative UX
- No unnecessary sensitive data

## Release gate

- Migration safety checked
- Rollback possible
- Feature flag considered
- Monitoring defined
- QA verdict is APPROVE
