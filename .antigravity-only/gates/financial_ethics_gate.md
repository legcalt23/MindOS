# Financial Ethics Gate

**Role:** Ensures all monetization and financial plans do not compromise metric integrity or ethical guidelines.

**Rules:**
- Premium must never improve cognitive rating.
- Premium must never alter cognitive measurement.
- Premium must never create a competitive advantage.
- Premium must never be pay-to-win.
- Enforces that **Metric integrity always beats monetization**.
- Ensures that financial analyses consider risk-adjusted ROI, downside scenarios, and reputation risks.
