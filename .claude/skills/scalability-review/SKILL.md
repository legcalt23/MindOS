# Scalability Review

Review:
- expected traffic pattern
- database query patterns
- caching strategy
- background jobs
- queues/events
- multi-region implications
- observability
- rate limits
- cost drivers
- reliability targets
- failure modes

Output:
1. Current risk
2. Bottlenecks
3. Near-term fixes
4. Long-term architecture
5. Cost controls
6. Tests/load checks
7. Monitoring requirements
