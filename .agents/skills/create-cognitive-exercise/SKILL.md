# Create Cognitive Exercise

## 1. Cognitive target
Define exactly what the exercise trains.

## 2. Mechanic
Describe what the user sees, does, what is correct, what is an error, duration, and difficulty changes.

## 3. Scoring
Include accuracy, reaction time when relevant, consistency, error type, difficulty level, and improvement against baseline.

## 4. Adaptation
Specify when difficulty increases, decreases, when rest is suggested, and when the AI coach intervenes.

## 5. Safety
Do not make medical or IQ claims. Do not present results as a clinical diagnosis.

## 6. Implementation
Return data model, API needs, frontend components, analytics events and tests.
