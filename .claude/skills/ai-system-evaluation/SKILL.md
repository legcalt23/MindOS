# AI System Evaluation

Evaluate AI systems across:

1. task success
2. hallucination risk
3. safety boundaries
4. privacy exposure
5. latency
6. cost
7. fallback quality
8. prompt injection risk
9. evaluation dataset coverage
10. user trust

Required outputs:
- eval cases
- expected behavior
- failure modes
- logging requirements
- safety filters
- escalation rules
- red-team prompts
- acceptance thresholds
