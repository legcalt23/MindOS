# Enterprise Feature Brief

For any feature, produce:

## Strategy
- user segment
- pain point
- value proposition
- moat contribution
- monetization impact

## Product
- MVP scope
- premium scope
- non-goals
- user flow
- activation/retention loop

## Engineering
- data entities
- APIs/services
- frontend surfaces
- permissions
- observability

## AI
- prompts or model behavior
- memory/retrieval needs
- evals
- safety boundaries
- fallback behavior

## Metrics
- north-star contribution
- activation metric
- retention metric
- quality metric
- risk metric

## QA
- edge cases
- test plan
- release gates
- rollback plan
