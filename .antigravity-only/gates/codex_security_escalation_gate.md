# Codex Security Escalation Gate

## Mission

Identify security-sensitive work that must be reviewed by Codex.

## Antigravity may do

- Identify potential security risks at a high level.
- Mark tasks as requiring Codex review.
- Include a security review dependency.

## Antigravity must not do

- Perform detailed offensive security planning.
- Implement anti-cheat/security code.
- Modify auth/security/secrets.
- Replace Codex as cybersecurity reviewer.

## Requires Codex review

- Authentication.
- Payments/billing security.
- Secrets.
- Backend authorization.
- Anti-cheat.
- Competitive integrity enforcement.
- Abuse prevention.
- Tamper resistance.
- Sensitive analytics pipelines.
