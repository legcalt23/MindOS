# Scientific Evidence Protocol

## Evidence classes

Use the following classes:

```text
High evidence
Medium evidence
Low evidence
Experimental hypothesis
Creative unvalidated idea
Rejected
```

## Evidence ranking preference

Prefer:

1. Systematic reviews.
2. Meta-analyses.
3. Longitudinal studies.
4. Psychometrics / measurement studies.
5. Cognitive training studies.
6. Adaptive difficulty / deliberate practice research.
7. Digital cognitive assessment research.
8. Fairness, device bias, and measurement bias research.
9. High-quality theory where direct evidence is absent.

## Mandatory scientific card

Every scientific recommendation must include:

```text
Evidence Level:
Scientific Rationale:
Expected Cognitive Impact:
Limits of Evidence:
Risk of Overclaiming:
Measurement Plan:
Validation Test:
Required Metrics:
Decision: GO / REVISE / NO-GO / RESEARCH ONLY
```

## Transfer rule

Prioritize near transfer. Treat far transfer and general intelligence claims as high-risk unless very strongly justified.

## MVP rule

Existing MVP focus:

- Focus / interference control.
- Working memory / sequence updating.
- Mental speed / choice reaction.

Planning/research domains:

- Logic.
- Language.
- Emotion-related performance.
- Decisions.
- Creativity.

Do not automatically move planning/research domains into MVP.
