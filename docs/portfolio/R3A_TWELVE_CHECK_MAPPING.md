## Conservation

- **12 → 12.** No deletion, no merge, no split.
- **4 changed, 8 untouched.** Of the 4: two MIGRATED (P8-05, P8-12), two strengthened in place (P8-09, P8-10).
- **Every change is a strengthening.** No property was relaxed to make the migration pass. The two properties that
  moved (P8-05, P8-12) both gained a fingerprint they previously lacked.
- **Falsifiability:** each check declares an `expectedFailureCode`; `contractViolations()` fails the run as
  `INFRA_ERROR` if any check lacks one — a check that cannot say *why* it failed cannot be verified.

## Denominator cannot shrink

`reconcile()` (`phase8-checks.mjs`) enforces, before any verdict:

1. every registry id has a result (`missing result for X`);
2. no result exists outside the registry (`unknown check result "X"`);
3. every state is a known `CHECK_STATES` member;
4. `counts` sum **exactly** to 12 — an exception cannot shorten the list.

Proven live, not asserted: an exception injected at check 4 yields **3/12 with 9 ABORTED, exit 1** — not "3/3 PASS".
Adversarially covered by `phase8-adversarial-tests.mjs` P8A-00…P8A-10, four of which mutate and **execute the real
runner** in a disposable copy.
