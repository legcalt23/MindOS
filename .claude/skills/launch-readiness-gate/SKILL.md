# Launch Readiness Gate

Review:
- product value
- UX completeness
- technical correctness
- security/privacy
- analytics
- QA coverage
- support readiness
- legal/compliance risk
- copy/claims
- rollback plan

Verdict:
- LAUNCH
- LAUNCH WITH CONDITIONS
- BLOCK

Include required fixes and exact acceptance criteria.
