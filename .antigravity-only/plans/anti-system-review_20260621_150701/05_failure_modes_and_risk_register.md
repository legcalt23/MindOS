# Failure Modes and Risk Register

This document registers the strategic, technical, and operational failure modes of the `/anti` subagent reviews, outlining their severity, triggers, impact, detection methods, mitigations, owners, and acceptance criteria.

---

## Risk Register Table

| Risk ID | Risk Title | Severity | Trigger | Impact | Detection Method | Mitigation Strategy | Owner | Acceptance Criteria |
|:---:|---|:---:|---|---|---|---|---|---|
| **RSK-01** | **Veto Bypass via Crash** | `CRITICAL` | Subagent crashes or encounters API quota limits during execution. | Unsafe plans proceed without critical safety checks. | Orchestrator logs a non-responsive agent during execution. | Implement programmatically enforced fail-safe routing: halt run and exit code 1 if any active squad member fails. | Orchestration Architect | The system terminates execution and sets final status to `INCONCLUSIVE_BLOCKED` when a squad member crashes. |
| **RSK-02** | **Fake Verdict Spoofing** | `CRITICAL` | Parent agent simulates opinions or non-invoked agents under mock fallbacks. | Fake approval reports are published with spoofed IDs. | Verification script checks conversation IDs against active registry logs. | Disable `FALLBACK_PROMPT_SIMULATION` fallback. Enforce real API validations. | QA / Evidence Lead | Runs without API-verified, distinct Conversation IDs are rejected. |
| **RSK-03** | **Prompt Injection Attempt** | `HIGH` | Input payload contains malicious instructions targeting the subagents. | Subagent ignores safety guidelines and runs unauthorized actions. | Prompt analyzer scans input for system instruction patterns. | Wrap input payloads in strict JSON boundaries. Implement instruction-isolation delimiters. | Prompt Engineer | System ignores instructions enclosed in input blocks and flags attempts. |
| **RSK-04** | **Token/Quota Exhaustion** | `HIGH` | Sequentially invoking multiple subagents exceeds API limits. | Review execution crashes mid-run, leaving partial logs. | API error response returns `RESOURCE_EXHAUSTED`. | Implement JIT Lazy Load. Enforce token budgets per review mode. | DevOps Specialist | Roster is simplified, and system execution is halted before budget is exceeded. |
| **RSK-05** | **Clock Tampering** | `HIGH` | Local clock is altered to bypass time-based quality gates. | Verification checks are bypassed by simulating expiration dates. | Preflight script compares local system time with external NTP source. | Enforce network NTP synchronization during preflight checks. | DevOps Specialist | Preflight fails if local time deviates from NTP by >60 seconds. |
| **RSK-06** | **Credential Leakage** | `HIGH` | Subagents read sensitive workspace environment files (e.g. `.env`). | Secrets and API keys are leaked into transcripts and log histories. | Preflight path audit detects unauthorized file reads. | Enforce directory path isolation. Restrict subagent read-access. | Security Guardian | Subagents are blocked from reading sensitive files at the adapter layer. |
| **RSK-07** | **Human Override Abuse** | `MEDIUM` | User manual overrides are applied to force approvals on failed gates. | Unsafe plans are marked as passed without addressing blockers. | Verification checks detect mismatch in override fields. | Require strict YAML override parameters in `OVERRIDE_LOG.md`. | Security Guardian | Human overrides cannot mark gates as passed, only record accepted risks. |
| **RSK-08** | **Package Overwrite** | `MEDIUM` | New reviews overwrite past package folders, destroying audit logs. | Historical audit records are lost. | Orchestrator checks if target path exists before creation. | Force unique timestamped directory generation. Prohibit deletes. | DevOps Specialist | Orchestrator errors out if a directory conflict occurs. |
| **RSK-09** | **Missing Hashes** | `HIGH` | Package generated without computing SHA-256 hashes. | File integrity is unverified. | Integrity ledger is empty or contains placeholders. | Compute file hashes programmatically and populate `package_integrity.md`. | QA / Evidence Lead | Runs fail verification if any file hash is missing or incorrect. |
| **RSK-10** | **Un-audited Veto Overrides** | `HIGH` | Manual vetoes are bypassed by deleting or modifying local markdown logs. | Strategic safety boundary is broken. | Verification script compares signed executive hashes. | Maintain signed hashes in local ledger. Reject modified verdicts. | Orchestration Architect | Preflight verification fails if executive verdict hashes do not match. |
