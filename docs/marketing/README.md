# Sistema de marketing de MindBoost

Home del sistema de marketing de MindBoost. **Orgánico-bootstrap (€0), España, opositores/estudiantes, Google Play, fundador en solitario.** Todo aquí honra la frontera de claims: la fuente de verdad del léxico prohibido es
`shared/src/commonMain/kotlin/com/mindos/app/features/mindboost/core/copy/ForbiddenLexicon.kt`.

## Regla núcleo (no negociable)

Ningún activo de marketing promete un resultado de capacidad general, de salud, de transferencia lejana ni usa
léxico de azar — **ni siquiera para negarlo**. El hype rechazado se representa por categoría entre corchetes
(p. ej. «[promesa de capacidad general]»). Ver [`CLAIMS_SAFETY.md`](CLAIMS_SAFETY.md).

## Cómo enchufan los agentes internos

- Estrategia/growth → `mindboost-growth-retention`, `mindverse-growth-engine`.
- Copy/conversión → `mindverse-copy-conversion` (siempre pasa por `CLAIMS_SAFETY.md`).
- Verificación de claims → skill `review-cognitive-claims` (checkpoint obligatorio antes de publicar).
- Monetización (cuando exista billing) → `mindverse-monetization-pricing`.
