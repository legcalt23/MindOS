# Mindverse Enterprise Agent Pack

This package adds specialized agents and skills for building Mindverse as a scalable AI-native platform.

## Compatibility

- Codex: `.codex/agents/*.toml`, `.codex/skills/*/SKILL.md`, `AGENTS.md`
- Claude Code: `.claude/agents/*.md`, `.claude/skills/*/SKILL.md`, `CLAUDE.md`

## Agent categories

- Strategy and platform architecture
- Product, onboarding, retention, and brand
- Engineering: backend, frontend, mobile, AI, data, DevOps, security, QA, performance
- Business: growth, pricing, enterprise, finance, legal, localization
- Trust, safety, community, support, curriculum
- Advanced Mindboost psychometrics and cognitive training

## Recommended first command

Use `prompts/PROMPT_TO_INSTALL_IN_PROJECT.md` in Codex or Claude from the root of your project.

## Important

These agents are not a substitute for legal, medical, financial, or security professionals. They are high-quality project agents that help create artifacts, reviews, implementation plans, code, tests, and risk analysis.
