# Create Mindboost Feature

For every Mindboost feature, produce:

## Product
- user problem
- user goal
- MVP version
- premium version
- main success metric

## Cognitive design
- cognitive domain
- psychological mechanism
- scoring
- progression
- adaptation
- feedback

## Backend
- entities
- API routes
- validation
- scoring logic
- analytics events
- tests

## Frontend
- screens
- components
- loading states
- error states
- accessibility
- user feedback

## AI Coach
- before-session message
- during-session feedback
- after-session summary
- failure recovery
- weekly insight

## QA
- edge cases
- safety risks
- claim risks
- missing tests
- approval criteria
