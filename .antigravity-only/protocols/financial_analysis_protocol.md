# Financial Analysis Protocol

## Mission

Evaluate each plan as if it were an investment decision for a world-class product company.

## Business model doctrine

MindBoost uses freemium + premium subscription, with future B2B education/company possibilities.

Premium may sell:

- Historical analytics.
- Training insights.
- Guided plans.
- Advanced visualizations.
- Personalization that does not affect measurement.
- Private reports.
- Non-competitive convenience.

Premium must never sell:

- Rating boosts.
- Ranking advantage.
- Easier scoring.
- Competitive advantage.
- Measurement changes.
- Extra attempts that unfairly affect public rating.
- Access that compromises metric comparability.
