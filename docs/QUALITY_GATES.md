# Mindverse Quality Gates

## Strategy gate
- Clear user segment
- Clear problem
- Clear value proposition
- Clear non-goals
- Clear moat contribution

## Product gate
- User flow is understandable
- First value is fast
- Retention loop is ethical
- Copy avoids overclaiming
- Premium value is meaningful

## Engineering gate
- Existing architecture inspected
- Small diff
- Tests included
- Typed interfaces
- Observability/logging
- Error states handled

## AI gate
- Prompt behavior specified
- Evals included
- Privacy boundary defined
- Fallback behavior defined
- Prompt injection considered
- Cost/latency considered

## Security/privacy gate
- Data minimization
- Access control
- Encryption where needed
- User control/deletion path
- No unnecessary sensitive analytics

## Launch gate
- QA passed
- Analytics verified
- Support prepared
- Rollback plan
- Risk owner assigned
