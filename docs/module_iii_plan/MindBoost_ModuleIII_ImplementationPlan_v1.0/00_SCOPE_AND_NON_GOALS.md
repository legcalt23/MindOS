# Scope and Non-Goals

## In Scope
- Bayesian Competitive Rating data model and algorithm.
- Offline simulation harness (100k+ synthetic sessions).
- Evidence Ledger executable gates for Focus, Working Memory, Mental Speed.
- Integrity, Comparability, Measurement Confidence decision objects.
- Session Validity and Explanation Contract.
- Non-compensatory rank formula.
- Matchmaking rules (simulation only).
- Ascension Trials algorithm (simulation only).
- Red-Team threat matrix (27 threats).
- Integration validation checks (25 checks).
- Simulation acceptance metrics (24 metrics).

## Non-Goals (Explicitly Out of Scope)
- Production deployment.
- Live Shadow Ranked.
- Public Ranked.
- User-facing UI.
- Real user data.
- Monetization, prizes, Pro Arena, Cash Challenges, Entry Fee Tournaments.
- Regulatory compliance implementation (KYC, AML, tax).
- B2B analytics.
- Minor safety implementation (placeholder only).
