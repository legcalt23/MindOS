# MindOS Founder Council Extended

This directory contains the active configurations, review modes, and guide protocols for the MindOS Founder Council Extended system featuring 36 session-real specialist subagents.

## Core Purpose
The Founder Council Extended is an elite, non-clinical strategic review system tailored for auditing MindBoost and MindOS roadmap features, scientific claims, scoring models, and Android performance timing without code modification access.

## Active Configurations
- `REALITY_STATUS.md`: Tracks session-real verification states.
- `ROUTING_MAP.md`: Configures task mapping parameters.
- `FOUNDER_COUNCIL_REVIEW_MODES.md`: Defines active squad structures (6 to 36 agents).
- `FOUNDER_COUNCIL_OUTPUT_TEMPLATE.md`: Formats report outcomes with vetoes and evidence grades.
- `BOOTSTRAP_FOUNDER_COUNCIL.md`: Provides the dynamic setup configuration block.
- `FOUNDER_COUNCIL_USAGE_GUIDE.md`: Contains templates for copy-paste request triggers.
- `SESSION_BOOTSTRAP_REQUIRED.md`: Details registration lifecycle steps.
